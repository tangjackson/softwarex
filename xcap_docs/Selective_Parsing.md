Selective Parsing menu enables user to select a Parameter to conduct Parsing.

Procedure

Procedure is shown below.

1. Open a New window, select a log file and click Selective parsing in Option.

2. Click Import button in Selective parsing option window to individually Import attached files.

3. Select a column and click Edit to confirm the selected Parameter. Parameter can be added or deleted.

Note) It is currently only supported for Qualcomm LTE Parameter, and it is expected to apply to all chipset in the future.

4. Click Check button and click OK button to create a Model.

5. Tip) Select Log viewer option before creating the model to avoid creating Message viewer in order to create the Model more quickly.

6. Reparsing can be executed when further analysis is needed using Message viewer.
