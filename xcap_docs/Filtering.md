# Filtering

Filtering function enables you to analyze selected data only.

1. Click icon in main Tool bar, or go to main Menu bar - Tools - Filtering.

2. Filtering window appears.

Filtering Window

The detailed description of each item in Filtering window is as follows.

| Classification | Description |
|---|---|
| Filter List | Display the selected parameters. You may add, and delete the filtering list by using icons. Default filter list is good/bad coverage for WiMAX. |
| Parameter tree | Display parameters. Parameters you may select are activated and in black; otherwise parameters are in gray. |
| Parameter | Display the selected parameters. |
| Operator | Select operator among =, <>, >, >=, <, <=. |
| Value | Enter value in numbers and strings. |
| Linker | Select a logical operator; AND, OR, or None. |

3. Click icon on Filter List to add a new filter setting, or double-click on a blank space in Filter List.

4. Enter a new filter name.

5. If you want to delete a filter name, click on icon.

6. Drag-drop a parameter from the Parameter tree to filter section.

7. Set Operator, Value, and Linker by double-clicking the relevant sections.

Operator selection of Filtering Window

8. Click OK to save filter settings.

9. Right-click on a parameter in the parameter tree, and select filter names to apply filter settings in parameter windows.

Filtering in Tree

10. Double-click on the parameter or drag-drop it into the workspace to see filtered parameter window.

Note) If you open a filtered data on a map analysis window, the symbol of map data represents first letter of the filtered data file.

Note) Filter settings are applied to all analysis types; Graph, Map, Table, CDF, PDF.
